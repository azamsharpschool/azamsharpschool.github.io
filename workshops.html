Featured workshop

Building AI Applications with Foundation Models

July 11, 2026 • 11:00 AM – 2:00 PM CST

Apple's Foundation Models framework makes it easy to integrate on-device AI into your iOS applications.

In this hands-on workshop, you'll learn how to build intelligent features using the latest Foundation Models APIs introduced by Apple.

We'll start by generating structured responses using @Generable models, then explore how to extend your AI assistant with custom tools.

You'll integrate Foundation Models into a real SwiftUI application and learn practical techniques for persisting AI-generated content using SwiftData.

Whether you're just getting started with Foundation Models or looking to build production-ready AI experiences, this workshop provides practical examples you can immediately apply.

What you'll learn

Build a complete AI-powered workflow.

01

Structured Responses with @Generable

Learn how to generate strongly typed responses using the @Generable macro so Foundation Models can return predictable data instead of only plain text.

02

Working with Tools

Give Foundation Models access to your application's capabilities through custom tools and learn how models invoke those tools inside AI-powered workflows.

03

Integrating Foundation Models in SwiftUI

Build an end-to-end AI experience inside a SwiftUI application including prompts, responses, streaming results, and responsive AI interfaces.

04

Building a Persistent AI Experience

Use SwiftData to store generated content so users can revisit previous sessions, with practical modeling and persistence techniques.
